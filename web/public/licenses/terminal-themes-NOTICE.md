# Terminal themes

HMux Dark is an original HMux palette. Other palettes are adapted from the following pinned upstream terminal ports. ANSI colors 0–15, background, foreground, cursor and selection retain upstream values. The extended palette is standard xterm except HMux muted diff fills at indices 22/52. Tokyo Night’s optional extended 16/17 overrides are not imported. Explicit truecolor output is unchanged.
